# Week 13（Day 85–91）FlashAttention：一次小优化实验（闭环）

## 本周目标

- [ ] 完成一次“有效的小优化闭环”：改动前后有可复现的收益或明确的退化原因，并用 profile 解释。

## 实验规则（强制）

- [ ] 只改一个变量（一个 commit/一个 patch）
- [ ] 固定 shape 与测量方法
- [ ] 必须保 correctness（误差对齐）

## 任务清单

- [ ] 在 `kernels/flash-attn` 的选定路线里实现你的改动
- [ ] 运行 baseline 与 new version 的对比
- [ ] 用 `ncu`/`nsys` 给出证据链

## 本周产出（必做）

- [ ] 改动记录：你改了什么（参数/布局/预取/向量化等）
- [ ] 对比结果：至少 2 个 shape 下的时间/吞吐变化
- [ ] 解释：收益来自哪个瓶颈改善；如果变慢，变慢原因是什么（寄存器/占用率/bank conflict 等）
